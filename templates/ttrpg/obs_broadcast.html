Battle Map on Stream

The map is a browser source — just the map, not your screen or a browser window. It follows the live map, shows it through the active player's eyes (fog and all), and falls back to your title card when no map is running. Build / refresh party scene creates the {{ cfg.map_scene }} scene for you to cut to.

Takes effect on the stream within a couple of seconds — no saving, no reload. Auto holds the 2D map and cuts to 3D only when the featured player moves, runs one look-around, then cuts back. 3D needs a floorplan and a player on the map; without either it shows 2D.
OBS keeps a browser source's page loaded until you reload it, so after a ScenePlay update the stream can still be running the old map page. Use this if the map ignores a setting you just changed.

{% if cfg.music_cable %}
Music → OBS from Windows

Windows has no capture sink for the music, so it travels through a virtual audio cable: the player sends sound into one end, the feed tab captures the other. Every step is one-time setup.

music player → CABLE Input ▷ CABLE Output → feed tab → OBS
                                    ╰→ "Listen" → your speakers
1. Install VB-CABLE (once)

Download from vb-audio.com/Cable, run the installer as administrator, reboot. Do not make the cable the Windows default output — only the music belongs in it.

2. Point both ends at it (this page, below)

Music output device → CABLE Input. Device vdo.ninja should send → CABLE Output. The player picks up the device on the next track, so skip one after changing it. (ScenePlay-Music is the Linux default and matches nothing on Windows.)

3. Keep hearing it yourself

The cable takes the music off your speakers. Mirror it back: Win+R → mmsys.cpl → Recording → double-click CABLE Output → Listen tab → tick Listen to this device → play back through your real speakers. It cannot echo into the stream — the feed reads the cable, not the speakers.

4. Start the feed

Click ♫ Start the music feed and leave the tab open (audio only — no camera). Allow the microphone prompt: the "microphone" is the cable. Reopen the link after changing settings — the device name is baked into it. In OBS, the ScenePlay Music Feed meter should move.
