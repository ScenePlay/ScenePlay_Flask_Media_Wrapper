    Browser Extensions
    
                
    
                  The extension is the easiest way to get media off youtube.com.
                  While you're on a video or playlist page, click the ScenePlay icon
                  and hit Send — the page you're watching goes straight to this
                  server as an MP3 or MP4. No copying the link, coming back to this
                  page, and pasting it into the Youtube Import form. The popup
                  remembers your server, format, and scene, so after the first
                  setup each new video is a single click.
                
    
                
                
                  ScenePlay for Firefox (signed)
                 | 
                ScenePlay-chrome.zip
                 | 
                firefox .xpi (unsigned, dev)
                
    
                  
    Firefox (use the signed link above):
    
                  
      
                    
    • Click the link. Firefox will offer to install the extension.
      • 
                    
    • If no install prompt appears, allow this site to install add-ons when Firefox asks.
                        Or download the file and drag it onto the about:addons page.
      • 
                    
    • This build is Mozilla-signed. It works on regular Firefox and stays installed.
      • 
                  
    
                  
    Chrome:
    
                  
      
                    
    • Download ScenePlay-chrome.zip and unzip it.
      • 
                    
    • Open chrome://extensions and turn on Developer mode.
      • 
                    
    • Click "Load unpacked" and pick the unzipped folder.
      • 
                  
    
                  
    Firefox dev build (unsigned) — only if you know you need it:
    
                  
      
                    
    • Installs only on Firefox ESR, Developer Edition, or Nightly.
      • 
                    
    • First set xpinstall.signatures.required to false in about:config.
      • 
                  
    
                  
    Saved settings (server URL, scene) survive reinstalls in every case.
