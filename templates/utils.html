    Import Backup
    
                    
                    
    
                    
                    
      
                      
    • Imports campaigns, scenes, media, and homebrew library entries.
      • 
                      
    • Anything this server already has is skipped (matched by video id or name).
      • 
                    
    
                    
                    
      
                      
    • Adds characters, sessions, battle maps, monsters, tokens, notes, and scene lighting.
      • 
                      
    • Sessions and maps with the same name are combined.
      • 
                      
    • A character that already exists here (same owner and name) is kept as-is.
      • 
                      
    • Imported characters whose player has no account here are placed under your account.
      • 
                      
    • Play history (dice rolls, played counts) is never imported.
      • 
                    
    
                    
                    
      
                      
    • Everything currently on this server is replaced.
      • 
                      
    • A safety snapshot of the current data is taken first.
      • 
                    
    
                    
                    
      
                      
    • Use on low-memory machines (like a Pi Zero), where unpacking a large
                          media folder can crash the restore.
      • 
                      
    • If you need the images, copy the static/uploads folder over separately.

    Browser Extensions
    
                
    
                  The extension is the easiest way to get media off youtube.com.
                  While you're on a video or playlist page, click the ScenePlay icon
                  and hit Send — the page you're watching goes straight to this
                  server as an MP3 or MP4. No copying the link, coming back to this
                  page, and pasting it into the Youtube Import form. The popup
                  remembers your server, format, and scene, so after the first
                  setup each new video is a single click.

    • Download ScenePlay-chrome.zip and unzip it.
      • 
                    
    • Open chrome://extensions and turn on Developer mode.
      • 
                    
    • Click "Load unpacked" and pick the unzipped folder.
